## 版本亮点

- **独立 Rust YAML 语言服务**：编辑器改用 `yaml-language-server-rust` v0.1.0 单一可执行文件，移除 Node.js、npm 与 `node_modules`，发布包不再需要 Node 运行时。
- **更小的发布包**：便携包从约 76.6 MB 降至约 42.2 MB，安装包约 51.9 MB。
- **功能保持**：保留 schema 驱动的补全、诊断、悬停与格式化；补充 `**/*.yaml` / `**/*.yml` 匹配，嵌套目录配置也能关联内置 Clash schema。
- **依赖校验**：Rust LSP 压缩包和解压后的 `yaml-language-server.exe` 均按 SHA-256 校验。

## 升级提示

- 如果曾根据旧示例创建过程序目录下的 `lsp-servers.json`，请把 `command` 改为 `${app}/lsp/yaml-language-server.exe`，`args` 只保留 `["--stdio"]`，并移除 Node.js 与 `server.js` 相关配置。
- 开发者升级源码后请先运行 `scripts/fetch-deps.ps1` 或 `package.ps1` 更新依赖缓存；发布包已内置语言服务。
- 本版本继承 v0.1.2 的 TUN UAC 提权与系统代理自动恢复行为。
