## 修复内容

- **YAML 配置误报**：修复 Rust 语言服务器未在打开文档前应用 `yaml.schemas` 设置的问题。v0.1.3 会把正常的 Clash 配置交给 SchemaStore 的 `cfgd Profile` schema，导致 `mixed-port`、`dns`、`proxies`、`rules` 等字段被误报。
- 在打开文档前发送 `workspace/didChangeConfiguration`；默认禁用 SchemaStore，只使用内置 Clash schema。
- 修正 `workspace/configuration` 对 `yaml.*` 子项的返回值。

## 验证

- 使用实际订阅配置和内置配置验证，诊断数均为 0。
- 故意写错类型/枚举的配置仍返回 2 条 Clash schema 错误，校验功能正常。
- Release 构建通过，CTest 3/3 通过。

## 升级提示

- v0.1.3 用户建议直接升级到 v0.1.4；无需 Node.js。
- 如曾基于旧示例创建 `lsp-servers.json`，请使用 v0.1.3 起的新示例（独立 `yaml-language-server.exe`）。
