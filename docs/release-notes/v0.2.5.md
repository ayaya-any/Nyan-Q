## 版本亮点

- **全新原创 Q 版猫耳二次元角色图标**：采用透明背景异形轮廓与平涂赛璐璐描边画风，
  重新设计主应用图标（`app.ico` 及 `16–512 px` 多分辨率 PNG），在深色/浅色主题标题栏、
  Windows 任务栏与桌面环境下均保持清晰轮廓与高对比度。
- **5 套状态感知系统托盘图标同步重绘**：基于同一角色形象统一绘制全部 5 种状态托盘图标，
  像素级对齐，切换代理状态无位移抖动：
  - 待机 / 默认：灰调挑染与闭眼休息表情；
  - 规则模式：翠绿配色与 `:3` 表情；
  - 全局模式：湛蓝配色与微笑表情；
  - 直连模式：青蓝配色与 `-_-` 表情；
  - TUN 模式：紫罗兰配色与 `:3` 表情。
- **文档与界面截图全面刷新**：重新生成 `docs/screenshots/` 下全部 12 张应用界面截图
  （覆盖深/浅色仪表盘、代理、配置、连接、规则、日志、脚本、设置、配置/脚本编辑器及脚本测试），
  在 `README.md` 中新增系统托盘状态图标展示图与触发说明，并移除已废弃的旧版空白脚本页截图。

## 升级说明

- 本版本与 0.2.3 / 0.2.4 兼容：Helper 服务协议、数据目录与配置文件格式均未变化，
  升级不需要更新 Helper，也不需要额外的 UAC。
- 覆盖 `Nyan-Q.exe` 与 `docs/` 即可；便携包或安装包可直接覆盖安装。
- 现有 `NyanQHelperService` 保持原样；本次变更仅涉及图标资源与文档截图，不涉及内核与服务链路。
