## 版本亮点

- 修复 Helper 慢响应或分片响应被提前判定为通信失败的问题。
- 状态查询失败后自动重连，结合带认证的控制器探活和 Windows 进程状态核验，避免短暂通信失败被误判为内核退出。
- 补充请求阶段、底层错误、耗时、重试次数和状态核验日志，不记录令牌或控制器密钥。
- 连接、发送、读取及重试共用总超时，避免重试延长界面等待。
- 停止请求未获确认时恢复状态监测，避免界面卡在停止中或错误报告内核已退出。

## 升级说明

- 覆盖安装 `Nyan-Q-0.2.2-win64-setup.exe`。
- 升级后首次启用 TUN 时，程序可能请求一次 UAC 以更新旧版 Helper 服务。
- 配置、订阅和脚本保持不变。
