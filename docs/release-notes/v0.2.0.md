## 版本亮点

- TUN 模式改为常驻 Windows Helper 服务架构：首次启用只安装一次
  `NyanQHelperService`，GUI 仍以普通权限运行，不再重启整个应用。
- Helper 注册为 `AutoStart`，之后启动 Nyan-Q 会直接通过本地命名管道连接服务，
  不需要重复请求 UAC。
- 关闭 TUN 时停止 Helper 中的 Mihomo，并切回普通权限本地内核；Helper 自身继续常驻。
- Helper 使用 256 位令牌、受保护目录和独立 Core 副本，GUI 只向服务传递配置路径。
- 安装包升级到 Nyan Setup v0.1.2，并在安装包中声明 `NyanQHelperService`：
  - 覆盖更新时自动停止并恢复 Helper；
  - 卸载时停止并删除 Helper 服务注册。
- 系统代理仍使用当前用户的 Windows Internet Settings，不需要管理员权限；
  不遵循系统代理的程序可继续使用 TUN。

## 升级说明

- 从 v0.1.7 覆盖安装即可。首次开启 TUN 时会请求一次 UAC 安装 Helper。
- 覆盖更新后如果 Helper 版本与 GUI 不一致，会再请求一次 UAC 完成 Helper 更新。
- 关闭 TUN 后可以在设置页直接开启系统代理，代理地址仍为
  `127.0.0.1:<mixed-port>`。
- 完整架构、安全边界和手动卸载方式见 `docs/helper-service.md`。
