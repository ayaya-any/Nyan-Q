## 版本亮点

- 新增 JavaScript 配置覆写系统：基于 QuickJS 独立沙箱，支持同步/异步 `main(config, profileName)`、多脚本顺序执行、全局与订阅专属绑定、执行预览和差异查看。
- 新增远程 JavaScript 脚本：HTTPS/ETag/Last-Modified、SHA-256 变化检测、预期哈希固定、历史版本、回滚和更新前后差异；自动更新默认关闭。
- 编辑器语言能力改为内置插件：YAML 与 JavaScript 提供语法高亮、语法检查和代码补全，不再启动外部 LSP 进程，也不再分发 `yaml-language-server`。
- 安装包构建切换为 Nyan Setup：单文件静态链接安装器，无需 Inno Setup、.NET 或外部运行库；保留 VC++ x64 运行库前置检测。
- 脚本空状态、配置卡片操作和脚本关联信息等界面细节完善。

## 升级说明

- 旧版本创建的订阅、配置和设置保持兼容。
- 之前通过 `lsp-servers.json` 配置的外部 YAML 语言服务不再使用；编辑器语言功能已内置。
- 新版安装包由 Nyan Setup 生成，可直接覆盖安装；卸载默认保留 `%LOCALAPPDATA%\Nyan-Q` 中的配置和订阅。
