## 版本亮点

- 编辑器新增 **一键格式化**：YAML 配置编辑器与 JavaScript 脚本编辑器支持
  `Shift+Alt+F`（或编辑器工具栏的 ✨ 按钮）。YAML 会按块结构统一为 2 空格缩进、
  对齐注释、折叠多余空行，并让块标量（`|` / `>`）与多行标量内容随父级缩进整体平移；
  JavaScript 整理代码缩进与空行。
- **YAML 格式化带语义校验**：格式化后重新解析并与原文比较解析事件（键、值、标签、
  锚点、文档数），一旦检测到结构变化就取消并提示，避免破坏配置；语法错误、多文档
  也会拒绝格式化。注释与块标量内容不会被丢弃。
- **JavaScript 格式化保持内容不变**：只调整代码行缩进与多余空行，不改变换行位置、
  运算符空格和引号风格；字符串、正则字面量、注释以及模板字符串的跨行内容原样保留。
- 格式化作为**单个撤销步骤**，`Ctrl+Z` 可整体还原；超过 4 MB 的文档会跳过。
- 语言插件接口新增可选的 `supportsFormatting()` / `format()`（`FormatResult`），
  新增语言可复用同一快捷键与编辑器集成。
- 配置编辑器与脚本编辑器的快捷键提示、README 与
  [内置语言插件](../language-plugins.md) 文档已同步更新。

## 升级说明

- 本版本与 0.2.3 兼容：Helper 服务协议、数据目录与配置文件格式均未变化，
  升级不需要更新 Helper，也不需要额外的 UAC。
- 覆盖 `Nyan-Q.exe` 与 `docs/` 即可；便携包或安装包可直接覆盖安装。
- 现有 `NyanQHelperService` 保持原样；只有启用 TUN 时才与 Helper 交互，本次变更
  不涉及该链路。

## 已知限制

- 格式化为保守的缩进/空白规范化：不改变 YAML 注释文本、键值顺序、引号风格，
  也不做 Prettier 级别的换行重排；遇到无法安全重排的块结构（例如多行标量依赖
  特殊缩进）会提示并放弃，而不是冒险改动。
- JavaScript 仅调整缩进与多余空行，不修改对象/数组换行、分隔符位置或运算符空格。
- 格式化与实时诊断一样限制为 4 MB 以内的文档。
