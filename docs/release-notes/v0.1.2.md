## 版本亮点

- **TUN 模式 UAC 提权**：开启 TUN 时会请求管理员权限并自动重启为管理员实例；启动时检测到 TUN 已启用也会先提示提权，取消授权则关闭 TUN。
- **系统代理自动恢复**：系统代理偏好写入 `settings.ini`，应用重启或 TUN 提权重启后，内核就绪会自动恢复系统代理。
- **文档与截图**：更新 README 的深色/浅色仪表盘截图，并补充内置语言服务组件说明。

## 升级提示

- 旧版本没有保存系统代理偏好，升级后请手动开启一次系统代理，之后重启会自动恢复。
- 通过 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 开机自启时进程不会提权；如需开机即启用 TUN，建议改用任务计划程序并勾选“以最高权限运行”。
